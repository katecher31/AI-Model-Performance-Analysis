# Kate's Analysis

This folder contains Kate's code and analysis for the AAI-500 final team project at the University of San Diego.

## Contents

- `kate_request_characteristics_eda.ipynb`
  - Exploratory data analysis of request/input characteristics
  - Response time by input type
  - GPU utilization by input type
  - Workflow-level latency analysis
  - Relationship between workflow size and total workflow duration

- `kate_multiple_regression.ipynb`
  - Multiple regression analysis of model response time
  - Additive and interaction model comparison
  - Regression diagnostics
  - Log-transformed response-time model
  - HC3 robust standard errors
  - Interpretation of model and input-type effects

## Research Focus

The analysis examines how model choice and request characteristics are associated with response time and how these findings may support model selection in a multi-model workflow.

These files represent Kate's contribution to the exploratory analysis and candidate regression modeling for the final team project.
